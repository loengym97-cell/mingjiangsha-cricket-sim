# 斗蛐蛐 · 离线工作台

**打开：双击 `F:\斗蛐蛐\打开斗蛐蛐.bat`。** 浏览器会打开 http://127.0.0.1:8765 。这是独立项目，本机已安装Python，无需联网。

完整操作步骤见 [使用说明.md](使用说明.md)：打开、查看逐局回放、选择AI运行、下载结果、备份与常见问题。只看已有结果时，无需重新模拟。

后续AI接手请先读 [HANDOFF.md](HANDOFF.md)，项目约定在 [AGENTS.md](AGENTS.md)，新增武将AI步骤在 [ai/README.md](ai/README.md)。

| 入口 | 用途 |
|---|---|
| `打开斗蛐蛐.bat` | 启动或复用后台服务，打开工作台 |
| `重启斗蛐蛐.bat` | 修改AI后重新加载；运行中的模拟会阻止重启 |
| `关闭斗蛐蛐.bat` | 关闭后台服务，保留数据，便于备份 |

三个入口都在本目录。浏览器关闭后服务仍在后台；再次双击打开入口即可。不要直接双击 `ui.html`。

第4批为基线对基线10000局，第5批为双方新版10000局。分析见 [AI改进报告.md](AI改进报告.md)。第1至3批缺少部分修正规则，不应与新规则胜率混用。现有历史对局和源码快照均保留。

## 规则要点

王濬、甘宁各6血、结束留牌上限3；其他角色在自身配置中设定。起手各4张，每回合摸2张。手牌上限只在弃牌阶段检查。三个装备栏可混放类型、可重复同名装备；云锦袍离场导致超额时随机弃置。距离和武器范围生效。濒死自救失败，第一个死亡者立即判负，停止后续结算。

回合上限默认300，达到上限标为“未结束”，属于计算截断，不是平局，也不强行判胜。AI只使用己方手牌与公开状态。易替代范围、识破反制链等近似仍记录在 `rules.json`；模型结果不直接代表实战胜率。

## 命令行与验证

Python 3.10+，程序运行只需标准库。以下命令均在 `F:\斗蛐蛐` 中运行：

```powershell
# 审核牌表与规则
python simulator.py --audit

# 小规模试跑；--diagnostic表示接受当前模型近似
python simulator.py --diagnostic --games 100 --left-ai v3 --right-ai v7 --check

# 正式保存一批完整回放，界面也能看到
python simulator.py --diagnostic --games 10000 --save-details --left-ai v3 --right-ai v7

# 规则、策略、存储与启动相关测试
python -m unittest discover -s . -p "test_*.py" -q
```

命令行AI默认基线v1，使用新版时显式传入上面的版本参数。不要同时通过命令行和界面启动多批任务。每个批次按两局共享种子、交换先手；奇数局的先手分配相差一局。

`experiments.py` 用于快速策略比较，`analyze_losses.py` 用于败局复查；快速比较仅保存统计，不混入完整批次列表。`test_browser.py` 使用额外的Playwright与本机Edge检查现有完整批次和临时数据库，不修改正式结果。
